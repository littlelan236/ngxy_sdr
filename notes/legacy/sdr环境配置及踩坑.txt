## gnuradio + pluto 踩坑
1，关掉杀毒软件 会把安装的gnu杀掉
2，gnu的embedded python block：
 - 使用这个的要单独建一个文件夹
 - 用记事本打开 复制到vscode里面去 不然在vscode里打开，有的时候软件偷偷换了一个.py文件 更改就无效了
  - 与numpy数据格式的换算： np.complex64 np.float32 np.int32(->int) np.int16(->short) np.int8(->byte)
3, 有的时候接收端会失效（接收到的信号一直时I为大于零的某个值 Q一直为0）目前不知道是什么原因
不要连续开始运行两个gnu流程图 点开tx后间隔一段时间再点开rx 可能能避免问题
4，symbol sync模块不能直接把250k幅值的数据输进去 会崩 要先过个multiplier把数据的幅值弄小
5，插Pluto的时候必须插边上的USB2.0
6，莫名其妙重启、unable to create iio context、failed to set BB rate这种：是一路供电不足 需要再连一根线 //但是有的时候两根线会触发电脑外设电涌保护 这种时候反倒连一根线是对的
7，不用每次连接pluto都串口登录一次系统 等电脑识别到“U盘”的时候就能直接代码用

## gnuradio usb转网口 配置ip
三四百块的国产pluto nano：
ifconfig usb0 无效
vi /etc/network/interfaces 修改配置 无效
有效的方法：
fw_setenv ipaddr 192.168.3.2


如果pluto端修改成功 但是PC Ping不通：
或ERROR: READ LINE: -32
ERROR: No context at 192.168.2.4
Scanning for IIO contexts failed: Not enough space (12)
修改PC端 静态ip：
- 打开“控制面板” → “网络和共享中心” → “更改适配器设置”。
- 找到 USB 网络适配器（可能显示为“以太网”或“RNDIS”），右键 → “属性”。
- 双击“Internet 协议版本 4 (TCP/IPv4)”。
- 如果当前是“自动获得 IP 地址”，则说明 PC 尝试通过 DHCP 获取 IP，但设备侧没有 DHCP 服务器（除非你专门配置了）。这时应该改为“使用下面的 IP 地址”，手动设置：
- IP 地址：192.168.3.100（或同网段的其他地址，不要与设备冲突）
- 子网掩码：255.255.255.0

## 原装plutosdr（有网线版）
设置网线连接静态ip：
vi /mnt/jffs2/autorun.sh

#!/bin/sh
# 删除可能冲突的 Avahi 备用地址
ifconfig eth0:avahi 0.0.0.0 down
# 配置 eth0 的静态 IP
ifconfig eth0 192.168.1.100 netmask 255.255.255.0 up

chmod +x /mnt/jffs2/autorun.sh
reboot

若通过这种方式配置 则不要将usb0的ip也配置到同一子网下！（192.168.3.x视为同意一子网）不然会冲突

不要忘了改PC端的静态ip
